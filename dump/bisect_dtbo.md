# dtbo 条目二分进度（2025）

信号定义：
  ACCEPT = 进 Qualcomm 900E（ABL 接受、内核启动）
  REJECT = ~5.3s 回 fastboot 或回落 A 槽

| 保留条目 | 数量 | 结果 |
|---|---|---|
| 全部 0-44（原厂文件） | 45 | ACCEPT (900E) |
| 全部 0-44（工具重建）   | 45 | ACCEPT (900E)  <- 工具已验证 |
| 0-22                    | 23 | ACCEPT (900E, t+8s) |
| 仅 2                    |  1 | REJECT (回落 A) |

已知约束：仅条目 #2 不够；需要集 S 是 {0..22} 的子集，且 |S| >= 2。

下一步（设备当前在 900E，需拔线+长按电源 30-40s 后进 fastboot）：
  测试 保留 0-11  (12 条)
    ACCEPT -> S 在 {0..11} 内
    REJECT -> S 与 {12..22} 有交集

后续每步继续折半，直到 |S| 最小。
注意：每次 ACCEPT 都会让设备进 900E，需要手工恢复一次。
